# Lenses

Pick one lens per question. Each row gives a question to adapt to the idea.
Sources: Koestler, Kaplan & Simon, Gentner, Boden, TRIZ, Polya, Kauffman, Rothenberg; Orchestra Research brainstorming frameworks.

## Which lens when

| Symptom in the user's answers | Lens |
|---|---|
| Sees the problem only one way | Reframe |
| All ideas come from one field | Distant analogy, Bisociation |
| Dismisses something as "too weird" | Negate |
| Idea is "+a bit better" | Constraints |
| Too many options | What changed |
| Stuck choosing A or B | Both A and B |
| Vague benefit ("people will like it") | Stakeholders, Problem-first |
| Elaborate design | Simplest version |

## Lenses

| Lens | Question to adapt |
|---|---|
| **Problem-first** | Who exactly has this problem, how often, and what does it cost them today? |
| **Solution-first** | Name two real problems this solves. Who asked for them? |
| **Reframe** | State the goal another way: different objective, different actor, different timescale. Does the problem get easier? |
| **Ladder up** | What is the general principle behind this? What class of problems does it belong to? |
| **Ladder down** | What is the smallest, most constrained version? What happens at the extreme (one customer, one student, one hour)? |
| **Constraints** | What must be true for this to work? Which of those is hard, which is habit, which is unstated? |
| **Negate** | What if the thing everyone assumes here were false? |
| **Distant analogy** | Describe the mechanism without domain words. Where else does that mechanism already work? |
| **Bisociation** | Combine one core concept from another of the user's fields with this idea. What appears? |
| **Both A and B** | What would a version look like that gets both sides of the trade-off? |
| **What changed** | What became possible in the last 6–18 months that makes this feasible now? What made it fail before? |
| **Boundary** | Where does this break: scale, hostile input, a different cluster flavour, over time? |
| **Simplest version** | What is the one key idea? Would a script, a checklist, or a manual step do 80%? |
| **Stakeholders** | How does <stakeholder> see this? (pick one from the table below) |
| **Two-sentence test** | "<Domain> struggles with <problem> because <reason>. <Approach> by <mechanism>, which works because <insight>." Can the user fill it? |

## Cross lenses (phase 3)

| Lens | Question |
|---|---|
| Compose | What appears if I<a> and I<b> become one thing? |
| Overlap | Does I<a> make I<b> unnecessary? |
| Tension | Do I<a> and I<b> compete for the same time or goal? |
| Shared asset | Can one piece of work serve both? |
