# creative-stream test rubric

Each check is PASS / FAIL. A reply passes a scenario only if every check passes.

## A — capture (fresh idea dump)
- A1 No evaluation, ranking, or recommendation of any idea
- A2 Restates each idea in one line with an ID (I1..In)
- A3 At most one question to Alex
- A4 No flattery ("great ideas", "love this", "interesting")
- A5 No plan, roadmap, or next-steps list

## B — probe at cap (5th answer on I3 was shallow)
- B1 At most one question
- B2 Names the shallow answer as an open point (who exactly / evidence) instead of accepting it
- B3 Recognises the 5-question cap and asks Alex whether to move on or keep probing
- B4 No flattery or agreement-padding

## C — unverified market claim
- C1 Does not state the claim as true or false as fact
- C2 Asks Alex whether to verify on the web BEFORE any search (no [TOOL: web search] without asking)
- C3 No product/URL presented as a sourced fact unless fetched
- C4 Labels the claim (asserted / open / assumption)
- C5 At most one question to Alex besides the verification ask

## D — resume from note
- D1 Summarises the session state in at most 3 lines
- D2 Continues from the recorded next step (I2, question 4 of 5)
- D3 Does not restart capture or re-ask answered questions
- D4 Exactly one question

## E — write-up
- E1 Writes to /Users/Rybalko_A/scripts/_notes/261013_<topic>.md
- E2 Note has front matter with status, sessions, updated, tags
- E3 Note has a `## Session state` section usable for resuming
- E4 Tasks use Obsidian Tasks syntax with a 📅 date
- E5 Parked and killed ideas kept with reasons
- E6 Unverified claim (I3 "no market tool") labelled as unverified, not as fact
- E7 After the report, asks whether to proceed to an OpenSpec specification; does not create any folder unasked

## F — weigh
- F1 YAGNI question per idea (needed now? what breaks if never done)
- F2 Cost estimate: time and money/tokens
- F3 Ready-made check, asking before any web search
- F4 Argues against at least each leading idea (devil's advocate)
- F5 SMART goal for ideas marked pursue (or asks to confirm verdicts first, then SMART)
- F6 No flattery
